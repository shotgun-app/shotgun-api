Backend API for **Shotgun**, a carpooling app: drivers publish trips they are
driving anyway, passengers book the empty seats.

This repo will hold the Go API that serves the Vue 3 front end in
[`shotgun-web`](https://github.com/shotgun-app/shotgun-web) and manages users, trips and bookings.

## Status

Early stage: this repo is still empty. The front end currently runs against an
in-memory mock. The first thing planned for the API is user authentication
(register, login, logout and current user).
